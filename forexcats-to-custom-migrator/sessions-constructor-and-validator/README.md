# sessions-constructor-and-validator — Контур Анализа Торговых Сессий

Репозиторий (каталог) **sessions-constructor-and-validator** представляет собой рабочий контур для комплексного анализа торговых сессий: от выгрузки минутных данных до создания, проверки расписаний и генерации готовых отчётов [1].

## 📂 Структура каталога

В каталоге представлены следующие директории, файлы кода и данных [2]:

| Расположение / файл | Роль и функционал |
| :--- | :--- |
| **`ipynb_files/`** | **Папка с исполняемыми ноутбуками и отчётами** |
| `ipynb_files/DavnLoad_Save_Quotes.ipynb` | **Загрузчик данных.** Подключается к ClickHouse, получает минутную активность котировок по символам, сохраняет отдельные JSON-файлы в `working_data_files/monitor` и сводную минутную плотность тиков в CSV. |
| `ipynb_files/Analysis_Sessions_Quotes.ipynb` | **Основной анализ реальных котировок.** Сопоставляет активность из JSON с расписанием сессий, ищет пропуски внутри сессий и котировки вне их, считает длительности и статистики, строит графики плотности тиков. |
| `ipynb_files/Analysis_Sessions_Candlesticks.ipynb` | **Альтернативный анализ по свечам.** Выполняет аналогичные проверки наличия/отсутствия данных, используя в качестве источника активности OHLC-свечи M1 из ClickHouse (`candlesticksM1`), а не сохранённые котировки. |
| `ipynb_files/sessions_conditions.ipynb` | **Конструктор расписаний.** Загружает `symbolsSessions`, `symbols`, `symbolsMarkets`; создаёт новые расписания по кластерам или группам тикеров, добавляет отсутствующие символы, готовит записи перед загрузкой и ищет дубликаты. |
| `ipynb_files/sessions_conditions_2.ipynb` | **Отчёт по текущим расписаниям.** Объединяет несколько внутридневных сессий в одну строку (например, `00:00-19:59; 21:00-23:59`), выявляет различия в расписаниях рынков, генерирует CSV и HTML-отчёты. |
| `ipynb_files/visualization_trading_sessions.ipynb` | **Визуализация расписаний.** Готовит данные для отображения сформированных CSV-расписаний, проверяет их согласованность внутри рынка и экспортирует HTML. |
| `ipynb_files/sessions_atoms_enriched.html` | **Готовый отчёт** по «атомарным» рынкам (инструменты внутри одного рынка имеют разные расписания). |
| `ipynb_files/sessions_full_enriched.html` | **Полный готовый отчёт** по инструментам с одинаковыми расписаниями внутри их рынков. |
| `ipynb_files/sessions_markets_summary.html` | **Сокращённая сводка** одинаковых расписаний на уровне рынков (без индивидуальной детализации по инструментам). |
| **`working_data_files/`** | **Рабочие файлы данных** |
| `working_data_files/monitor/*.json` | Исходные данные для анализа котировок: 1655 JSON-файлов (по одному на тикер) с минутной активностью, генерируемые загрузчиком. |
| `working_data_files/*.csv` | Актуальные промежуточные результаты: обогащённые расписания, списки атомарных рынков (`atoms_df`), однотипные инструменты (`similar_df`) и сводки кластеров. |
| **`log_data_files/`** | **Журнал результатов** |
| `log_data_files/*.csv` | История запусков: версии промежуточных и итоговых таблиц с временной меткой (служит журналом, а не исходным кодом). |
| **Прочие папки** | |
| `input_data/` | Резервная папка для входных данных (в данный момент пуста). |
| `ipynb_files/tests/` | Папка для тестов (в данный момент пуста). |

## 🔄 Основные рабочие процессы (Pipelines)

Контур логически разделен на две параллельные технологические цепочки [3]:

### 1. Анализ активности и нарушений котирования
```
ClickHouse 
   │
   ▼
[DavnLoad_Save_Quotes.ipynb] ──► working_data_files/monitor/*.json & CSV плотности тиков
   │
   ▼
[Analysis_Sessions_Quotes.ipynb] (или [Analysis_Sessions_Candlesticks.ipynb])
   │
   ▼
Выявление нарушений расписаний и построение графиков
```

### 2. Конструирование и документирование расписаний
```
SQL (symbolsSessions + symbols + symbolsMarkets)
   │
   ▼
[sessions_conditions.ipynb] (Создание / обновление расписаний)
   │
   ▼
[sessions_conditions_2.ipynb] (Генерация отчетов) ──► CSV и HTML-отчёты
```

---

## ⚠️ Важное разделение зон ответственности

При работе с расписаниями необходимо строго различать роли инструментов [3]:
*   **`sessions_conditions.ipynb`** — используется для **изменения и подготовки** расписаний.
*   **`sessions_conditions_2.ipynb`** — используется исключительно для **проверки и документирования** существующих расписаний.
