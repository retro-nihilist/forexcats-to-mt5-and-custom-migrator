# Calculation of Paid Spread per Trade

Расчёт уплаченного спреда по сделкам с учётом маркапа (markup).

## Описание задачи

Необходимо подготовить отчёт по сумме уплаченного спреда по сделкам, учитывая наш спред (маркап).

На staging-сервере предоставляется таблица сделок (SQL). Для каждой транзакции фиксируются поля:

| Поле          | Описание                                              |
|---------------|-------------------------------------------------------|
| `marketAsk`   | «Чистая» котировка Ask от провайдера на момент сделки |
| `marketBid`   | «Чистая» котировка Bid от провайдера на момент сделки |
| `marketSpread`| Спред провайдера                                      |
| `markup`      | Рассчитанный маркап на момент сделки                  |

### Требование

Добавить в выборку/таблицу вычисляемое поле:

**`spread_with_markup_usd`** — уплаченный спред с маркапом, выраженный в USD.

### Примечания

- Для конвертации в USD допускается использование текущего курса (на момент формирования отчёта), без исторических курсов.
- Ожидаемый результат: в таблицу сделок добавлена колонка `spread_with_markup_usd` по каждой сделке.

## Что делает ноутбук

1. **Загрузка данных**
   - В тестовом режиме (`IS_TEST_MODE = True`) читает SQL-дамп сделок из `input_samples/transactions.sql`.
   - В боевом режиме — из временных данных.

2. **Предобработка**
   - Парсинг VALUES из INSERT-запроса в DataFrame.
   - Приведение числовых колонок к корректным типам.
   - Фильтрация только сделок закрытия позиций (`entry == 1`).

3. **Расчёт спреда**
   - Пересчёт `marketSpread = marketAsk - marketBid`.
   - Расчёт фактического спреда сделки (`spread_calc`) в зависимости от направления (`action`).
   - Контрольное отношение `spread_check = spread_calc / marketSpread` (для выявления аномалий).

4. **Загрузка торговых условий**
   - Загрузка файла `trading_settings_sales_basic_df.csv`.
   - Мерж по символу.
   - Расчёт денежных значений спреда с учётом:
     - `markup + marketSpread`
     - precision символа
     - `point_money`
     - `contractSize`
     - объёма сделки (`volume`)

5. **Итоговый показатель**
   - `pos_price_3` — уплаченный спред в деньгах (эквивалент `spread_with_markup_usd` при курсе 1, если все инструменты уже в USD-эквиваленте).
   - Вывод общей суммы уплаченного спреда.
   - Сохранение результата в `report_df.csv`.
