# calculation_min_symbol_number_contracts_samples

Ноутбук для расчёта **минимального размера контракта** (contract size) по криптовалютным символам.

## Назначение

Для каждого крипто-символа подбирается минимальный `contractSize`, при котором:

- стоимость спреда на 0.01 лота ≥ **0.1**
- стоимость 1 пункта на 0.01 лота ≥ **0.0001**

Это нужно, чтобы в MetaTrader стоимость пункта и спреда корректно отображалась и не «обнулялась» из-за слишком маленьких значений.

## Что делает ноутбук

1. **Инициализация**
   - Динамический импорт утилит из `libraries_py`
   - Настройка путей к данным, логам и конфигурации

2. **Загрузка данных**
   - Таблицы `symbolsQuotes` и `symbols` из локальной MySQL
   - Объединение котировок с параметрами символов (`precision`, `name`, `path`)

3. **Фильтрация крипто-символов**
   - Чтение списка крипто-тикеров из файла `crypto_list.txt`
   - Отбор строк, у которых `name` содержится в этом списке

4. **Расчёт минимального contract size**
   - Для каждого символа итеративно увеличивается размер контракта (`1 → 10 → 100 → …`)
   - Условие остановки:
     ```text
     spread_cost ≥ 0.1  ИЛИ  pip_cost ≥ 0.0001
